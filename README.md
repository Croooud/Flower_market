# Fleur de Mer — сайт-витрина цветочного магазина

Мобильный сайт-витрина (Web App) для цветочного магазина в Новороссийске.

- Один файл `index.html`: Tailwind CSS (CDN), Google Fonts, Vanilla JS, встроенные SVG-иконки
- Каталог с фильтрами, корзина, заказ в WhatsApp с предзаполненным сообщением
- Допы к букету, условия доставки, отзывы, контакты с картой

Открыть: просто откройте `index.html` в браузере или включите GitHub Pages для ветки `main`.
